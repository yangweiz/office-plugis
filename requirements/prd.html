01 产品契约

主要用户是需要在 Microsoft Office 中完成公文制作、批量数据处理和演示文稿整理的办公人员。用户从插件功能区或功能搜索发起任务；任务以可检查的目标文档、数据区域或导出文件完成，并在失败时保留原件、给出可重试的原因。

触发打开 Word、Excel 或 PowerPoint 后，通过功能区、文档侧栏或搜索启动命令。
核心工作用去重后的统一能力完成排版、清理、转换、汇总拆分和文档切换，而非学习多套插件入口。
完成证据显示变更范围、输出路径、跳过项和失败项；破坏性操作可撤销或已有备份。

产品决策

本地优先。文档处理默认在本机完成。只有用户主动使用在线功能时，才发送该功能明确列出的内容；发送前展示数据范围和服务提供方。
一项能力，一个入口。相同页面设置、标题样式、红头页码、清理、图片、表格、汇总拆分等能力只保留一个命令，通过参数覆盖不同场景。
可信边界。不提供密码破解、VBA 密码去除、只读或保护绕过，不克隆无权编辑的受保护内容。正常解密与解除保护必须以用户提供有效凭据为前提。

范围依据为各产品官方公开页面，检索日期均为 2026-11-12：不坑盒子功能列表、方方格子、Office Tab、小恐龙、快点公文助手、公文处理助手、尚书公文助手。公开页面未披露的内部行为不推断为已覆盖。

02 范围与交付状态

目标环境为 Windows 10/11 上 Microsoft Office 2016、2019、2021 与 Microsoft 365 的 32/64 位 Word、Excel、PowerPoint。WPS、macOS、Linux、Publisher、Access、Project、Visio 不在当前范围内。

统一执行规则

  1. 预检：无打开文档、空选区、受保护范围、缺失依赖、无效路径或不支持的版本时，在执行前说明原因；不产生半完成输出。
  2. 原件保护：批处理、拆分、转换、导出默认写入新位置。发现同名文件时要求选择新名称或明确覆盖，不允许静默覆盖。
  3. 恢复：单项编辑优先使用宿主撤销；无法可靠撤销时先创建备份并明确提示。撤销不可用时不得显示“可撤销”。
  4. 取消：取消后停止接收新项，完成当前不可中断的最小步骤，列出已处理、未处理和已生成文件。
  5. 逐项隔离：单个文件或记录失败不抹掉其他成功项；结果包含输入、输出、状态和可读原因。
  6. 凭据：密码和密钥只用于当次授权操作或用户明确保存的连接；界面与日志均脱敏。

04 P0 功能需求

以下需求组成第一条完整旅程。选择筛选器可查看对应宿主；每项详细来源仍以功能矩阵为准。

FR-COM-01 功能发现、设置与帮助 P0

用户在功能区或搜索框输入名称、关键词后，只看到当前宿主可用命令；不可用命令显示原因而非无响应。设置按用户保存，损坏或不可读时保留原文件并回退到安全默认值。帮助展示当前版本、功能说明和依赖状态。

COM-001、COM-002、COM-006

FR-DOC-01 文档切换侧栏 P0

打开、新建、激活、重命名和关闭文档后，侧栏同步当前宿主的文档列表。用户可激活、保存或关闭单项，也可全部保存、全部关闭；未保存项逐个进入确认流程。颜色标记按文档标识恢复，不修改文档内容。侧栏是基础标签能力，不宣称等同于单窗口原生标签。

FR-W-01 页面与页码 P0

用户可选择公文页面模板或当前页面参数，设置 A4 版心、文档网格、页边距和页码。插入横页或将当前页转横页时保持前后内容顺序及节属性；页码支持居中、居右、奇偶外侧与横向页短边。信函首页独立规则在 P1 扩展，不在 P0 隐式启用。

W-PAGE-001、W-PAGE-002、W-PAGE-004、W-PAGE-007、W-PAGE-008

FR-W-02 公文样式与标题 P0

用户可对选区或全文应用大标题、正文和一至四级标题。自动排版只处理可识别段落，输出跳过项；标题提级、降级和修正不触碰普通正文。所有样式来自原创模板，用户明确选择后才替换同名自定义样式。

W-STYLE-001、W-STYLE-002、W-STYLE-003

FR-W-03 文本重排与清理 P0

断行重排保留真正的标题、列表和段落边界；空白清理分别提供段前、文中、空段和不可见字符选项；删除超链接保留显示文字；清理直接格式时保留用户指定的语义样式。默认作用于选区，未选择内容时必须确认全文范围。

W-TEXT-001、W-TEXT-002、W-TEXT-003

FR-W-04 红头、线条与常用部件 P0

用户可插入单行/多行文字红头、图片红头、红线、函线、分隔线、版记线、日期、文号、常用符号和短语。多机关名称保持对齐；图片由用户合法提供。部件插入位置可见且与正文不重叠，重复插入前提示。

W-PART-001、W-PART-002、W-PART-004

FR-E-01 区域编辑与清理 P0

用户可批量插入行列、横纵复制、转换文本/数值/日期、添加前后缀、删除不可见字符、空白行列和重复项。默认只处理显式选区；重复处理需定义比较列、首项保留和大小写规则，含公式或有效格式的行列不能被“看似为空”误删。

E-EDIT-001、E-EDIT-002、E-DEL-001、E-DEL-002

FR-E-02 汇总、拆分与工资条 P0

汇总前检查表头和字段类型，保留来源工作表信息；拆分支持复制型与剔除型，清洗无效工作表名并处理重名冲突；工资条按每位数据行复制标题和间隔。所有结果写入新工作表或新文件，原数据区域保持不变。

E-MERGE-001、E-SPLIT-002、E-PAY-001

FR-E-03 数据对比与排序 P0

数据对比按用户选择的键列出新增、缺失和不同项，可追溯到原行；数值比较允许明确容差。排序支持多键和稳定次序，颜色及合并单元格变体按同一模型扩展；无法安全处理合并区域时先阻塞而非破坏数据。

E-CMP-001、E-SORT-001

FR-P-01 页面与效果清理 P0

用户可按选中页或全稿删除空白页、隐藏页、动画和切换。空白页判定须忽略背景、母版和备注，不得把仅有备注的页面自动视为空白；隐藏页删除前列出页码并确认。清理动画不得删除形状或文本。

P-CLEAN-001、P-CLEAN-002

FR-P-02 配色、形状与图片导出 P0

原创配色只映射文本、背景和形状颜色，不重新着色图片。形状支持尺寸变化、横向/纵向对齐及翻转，组合对象作为整体处理。图片导出允许页码范围、格式和分辨率，输出重名时遵循统一冲突规则。

P-DESIGN-001、P-SHAPE-001、P-DOC-003

06 安全与连接型功能

FR-SEC-01 授权内安全操作

文档加密、正常解密、保护设置与有效凭据解除（W-SEC-001/002）只调用宿主正常流程。密码错误、权限不足或文件损坏时保留原状态，不反复自动尝试。破解、绕过和受保护内容克隆（W-SEC-003）为排除项。

FR-AI-01 用户自备在线服务

AI 写作/助手（AI-001）、OCR（AI-002）、翻译（AI-003）、提示词模板（AI-004）、发票读取（E-INVOICE-001）和朗读/转音频（P-PLAY-002）仅在连接配置有效后可用。发起前显示服务提供方、文本或图片范围及目标语言/声音等参数；支持取消、超时和服务错误提示，不把失败包装为成功。

FR-NET-01 分发、消息与互动

数据查询页（E-DIST-001）默认最小化公开字段，并要求访问控制；邮件或消息群发（E-COMM-001）提供预览、收件人授权确认、限流和逐项结果；手机遥控与弹幕（P-PLAY-003）采用配对授权、过期和断线重连。相关配套 Web 服务单独发布，不与桌面插件安装包混为一项。

07 异常、空状态与恢复
